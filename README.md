# Dashboard JDZ de Entrenamiento

Prototipo web para centralizar accesos, consultas y agenda de entrenamiento para Jefes de Zona.

## Publicación

El sitio está preparado para GitHub Pages usando `index.html` en la rama `main`.

## Contenido actual

- Acceso a EduAcción
- Acceso al Consolidado de Ingresos
- Evaluación de Periodo de Prueba
- Promociones y Arando Talento
- Consulta demo de Arando Talento por SAP
- Consulta demo de Entrevistas
- Agenda semanal de entrenamiento
- Indicadores visuales

## Seguridad

Este repositorio contiene únicamente un prototipo. No se deben publicar aquí datos personales reales, contraseñas, tokens ni información interna sensible. Para conectar datos reales de SharePoint, Excel o Microsoft 365 se debe usar una integración autenticada y segura.
